# Introduction

**Definition:** Ye section DSA patterns ka ghar hai — random problems hal karne ke bajaye patterns pehchano, kyunki interviews me wahi 20 patterns ghoom-phir ke aate hain. Har pattern page pe theory, JS templates aur grouped questions hain. Neeche wahi roadmap hai jo follow karne se DSA me behtar hoge.

## Roadmap (Phase-wise)

**Phase 1 — Foundation:** Arrays, Sorting, Hashing se shuru karo. Array manipulation, sort karna aur hash map se lookup — inke bina aage kuch nahi hoga. Har roz 2-3 easy problems isi phase se.

**Phase 2 — Array Techniques:** Prefix Sum, Two Pointers, Sliding Window, Intervals, Stack & Queue, Monotonic Stack, Linked List, Binary Search. Ye sab Phase 1 ke upar bante hain — pattern pehchanna seekho ("sorted hai to two pointers?", "range poochha to prefix sum?").

**Phase 3 — Recursion Track:** Recursion, phir Backtracking, phir Trees, phir Heap. Recursion samjhe bina backtracking aur trees me phasoge — isliye ye order pakdo. Trees ke baad Heap (priority queue) aasan lagta hai.

**Phase 4 — Graphs:** Graphs (BFS/DFS, topo, shortest path, MST), phir Union Find. Trees aate hon to graphs me sirf visited aur cycle ka farak hai.

**Phase 5 — Advanced:** DP, Greedy, Trie, Bits, Range Queries. DP sabse bada hai — uske 5 subtopics ek-ek karke karo. Greedy me proof socho, Trie/Bits/Range Queries need-based karo.

## How to Use These Notes

- **Pehle theory padho:** Har page ke upar Definition/When/How hai — pattern pehchanna hi aadhi jeet hai.
- **Skeleton trace karo:** Template code ko ek example pe haath se chalao, tabhi yaad rahega.
- **Grouped questions karo:** Har subtopic ke neeche diye questions usi pattern ke hain — pehle khud, phir solution dekho.
- **Ek pattern pakka karke aage badho:** Adhoora chhod ke next pattern me mat koodo.

## Revision Advice

- **Roz purana revise karo:** Naya pattern shuru karne se pehle pichhle pattern ka ek question dobara karo.
- **Templates yaad rakho:** Heap classes, DSU, Dijkstra, binary search bounds — ye copy-paste wale hathiyaar hain.
- **References use karo:** Har page ke end me links hain — jahan atko, wahan aur padho.
- **Speed nahi, pehchan:** Interview me jeet pattern pehchanne ki hai, tez likhne ki nahi.
